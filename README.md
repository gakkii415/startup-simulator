# 起業シミュレーター

複数の事業を、1つのリポジトリで独立して管理するための骨組みです。各事業のタスクは Markdown、成果物は事業別フォルダに保存します。

## 構成

```text
startup-simulator/
├── README.md
├── AGENTS.md
└── ventures/
    ├── business-a/
    │   ├── tasks.md
    │   └── artifacts/
    └── business-b/
        ├── tasks.md
        └── artifacts/
```

`business-a` と `business-b` は空の事業枠です。具体的な業種や事業内容は未設定です。`artifacts/.gitkeep` は空フォルダを Git で保持するためのファイルです。

## 使い方

1. 対象事業の `tasks.md` に事業名・概要を記入します。
2. 合意した作業を `- [ ] タスク内容` で追加します。着手時は行末に `（進行中）`、確認待ちは `（確認待ち）` と記し、完了後は `- [x]` に変えて状態表記を外します。
3. 成果物を同じ事業の `artifacts/` に保存し、該当タスクから `[成果物](artifacts/ファイル名)` でリンクします。

タスクの状態は各 `tasks.md` を正本とします。必要な下位フォルダは成果物が生じたときに追加します。

AIへの依頼例：

> business-a の tasks.md を確認し、記載済みの未完了タスクを1つ進めて。成果物は business-a の artifacts に保存し、タスクを更新して。

記載済みのタスクがない場合は、事業内容や次に行う作業をユーザーと決めてから追加します。

## 事業を追加する

`ventures/business-c/` のように重複しない名前のフォルダを作り、空の `artifacts/`（Git で保持する場合は `.gitkeep` も）と、次の `tasks.md` を追加します。既存事業のタスクや成果物をそのままコピーしないでください。

```markdown
# 事業Cのタスク

- 事業名：未設定
- 概要：未設定

## タスク

まだ登録されていません。合意したタスクをチェックリストで追加します。
```

## 今回の範囲

タスク管理と成果物保存の骨組みのみです。Web画面、自動実行、外部サービス連携、本番用リポジトリへの切り出し機能は含みません。本番へ進める際は、対象事業を独立リポジトリへ切り出す方針を改めて具体化します。

このリポジトリは公開されています。保存する内容は公開可能なものに限ります。
