# タスク一覧

[決定事項](decisions.md)

- [x] 事業を決める
  - 選択時：ユーザーがやりたい事業を端的に入力する。商圏は京都市（商圏は京都市でいいですか？と念の為確認を取る。もしユーザーからの修正があれば反映する）。事業内容が確定したら、AGENTS.mdの「事業フォルダの命名と変更」に従い、管理用フォルダ名を事業内容を表す名前へ一度変更する。
  - 決定内容：[カウンセリング事業](decisions.md)

- [x] 事業名を決める
  - 選択時：事業内容に合う名前をAIが15個ほどアイデア出しする。SEOやMEOも意識する。ユーザーが最終的な仮事業名を決める。
  - 決定内容：[カウンセリングルーム ことのま](decisions.md)

- [x] ロゴを作る
  - 選択時：AIがロゴ画像を作成する。基本的に事業名を洗練されたフォントで書けばOK。
  - 成果物：[ロゴ画像](logo.png)

- [x] メールアドレスを決める
  - 選択時：事業用メールアドレスとして使う文字列を決める。アイデア出しをAIがする。基本的に事業名.official@gmail.comにする。シミュレーションでは実際のアカウント作成はしない。
  - 決定内容：[使用予定メールアドレス](decisions.md)

- [x] 提供する商品orサービスを決め、料金表を作る
  - 選択時：提供する商品orサービスをAIがユーザーに提案する。ユーザーが修正および承認後、それぞれ価格をAIが顧客向けの料金表として完成させる。なお、周辺地域の競合の料金を確認し、それを踏まえて料金設定すること。また、周辺地域の競合の料金をユーザーに示すこと。
  - 成果物：[サービス内容・料金表](decisions.md)

- [x] 必要な道具を洗い出す
  - 選択時：事業開始・サービス提供に必要な道具、設備、ソフトなどを箇条書きで一覧化する。過剰にはしないこと。ユーザーが修正、追加、削除できる。ユーザーがチェックボックスでチェックできるようにする
  - 確認結果：[必要な道具](decisions.md)

- [x] 必要なスキル・知識を洗い出す
  - 選択時：この事業を実際に提供するために必要なスキル・知識を箇条書きで一覧化する。過剰にはしないこと。ユーザーが修正、追加、削除できる。
  - 確認結果：[必要なスキル・知識](decisions.md)

- [x] 商圏（母数）から顧客数を推定する
  - 選択時：AIが対象市場の母数を調査・推定し、現実的に獲得できそうな顧客数を試算する。なお、ターゲット数、セグメンテーション数、競合の数や規模を把握して試算すること。複数の適切な別の算出方法があるなら、複数の切り口で試算すること。必要性があればフェルミ定数を用いて算出してもよいが不要なら用いなくていい。試算において、修正が必要な箇所があればユーザが指摘する。

  - 承認済み試算：[月間顧客48人・月48回、維持に必要な新規顧客月8人（前提・競合比較を含む）](decisions.md#商圏母数からの顧客数推定)

- [ ] 初期の顧客をどう獲得するかニッチ戦略を決める
  - 選択時：ユーザーが決めてユーザーが入力する。それを促すためにAIからも提案する。

- [ ] 集客方法を決める（オーガニック？メール営業？）
  - 選択時：この事業に合う集客手段を比較し、実際に使う方法を決める。主にユーザーが決めて入力する。

- [ ] 1ヶ月あたりの売上を想定する
  - 選択時：想定顧客数と料金をもとに、1ヶ月あたりの売上をAIが試算する。ユーザーが修正できる。

- [ ] 1ヶ月あたりの費用を想定する
  - 選択時：事業を維持するために毎月発生するランニングコストを試算する。ユーザーが修正、追加、削除できる。

- [ ] 初期費用を想定する
  - 選択時：事業開始までに必要な費用を積み上げて試算する。ユーザーが修正できる。

- [ ] ホームページを作る
  - 選択時：実際に閲覧できるHPをAIで作成する。まずは画像生成でサイトのデザインをユーザーに見せる。ユーザーからOKが出ればサイトの作成をAIが行う。HPに必要な画像はネット上のフリー素材を使うかAIが画像素材を生成して用意する。SEOやMEOも意識すること。

- [ ] 予約フォームを作る
  - 選択時：この事業に必要な予約項目をAIが仮決めし、ユーザーが修正および承認後、仮の予約フォームを作る。

- [ ] Googleビジネスプロフィールを作る
  - 選択時：実際のGoogleビジネスプロフィールを想定して、掲載内容を仮で作る。必要な画像はフリー素材を使ったり、さらに必要があればAIで画像生成する。シミュレーションなので実際の申請はしない。

- [ ] 必要なSNSを作る
  - 選択時：必要なSNSを判断する。ユーザーが承認後、プロフィール、投稿内容などを実際のアカウントを想定してAIが作る。

- [ ] 1ヶ月あたりの利益と1件あたりの利益を想定する
  - 選択時：利益をAIが試算する。ユーザーが修正できる。
